# Симулятор автономного электрошаттла РУДН

Веб-симуляция беспилотного электрического шаттла, который курсирует по территории
кампуса РУДН (ул. Миклухо-Маклая) на малой скорости и «видит» окружение лидаром и
камерами. Три страницы: **симуляция**, **демо-режим для презентации** и
**редактор карты**.

```bash
npm install
npm run dev
```

Стек: React 19, TypeScript, Vite, three.js + React Three Fiber, zustand.

---

## Страница «Симуляция» (`#/sim`)

**Экран 1 — схема территории (вид сверху).** Ортографическая сцена: газоны, вода,
дорожная сеть, корпуса с подписями, деревья, маршрут с бегущими штрихами, три
остановки, положение шаттла, его след и сектор обзора. Здания и деревья
подсвечиваются в тот момент, когда по ним проходит луч лидара, — видно, что
именно сейчас «видит» машина.

**Экран 2 — облако точек лидара.** То же самое, но глазами датчика: точки
считаются лучевой моделью по тем же данным карты, поэтому картинка на двух
экранах совпадает по построению. Режимы камеры: погоня, вид сверху, свободный
облёт. Раскраска точек: по высоте, по силе отражения, по классу объекта.
Обнаруженные объекты обводятся рамками с номером трека и дальностью.
В углу — врезка одной из четырёх бортовых камер.

**Нижняя панель телеметрии:** скорость, режим автопилота, следующая остановка и
время до неё, двери, заряд батареи, пробег, круги, пассажиры, статистика
восприятия и предупреждение об экстренном торможении.

**Скорость симуляции** регулируется кнопками `−` и `+` в панели управления:
ступени ×0,5 · ×1 · ×2 … ×10. На ускорении шаг физики автоматически дробится на
подшаги не длиннее 50 мс, поэтому разгон, торможение и остановки на ×10 идут так
же точно, как на ×1.

Горячие клавиши: `Пробел` — пауза, `+` / `−` — быстрее и медленнее, `F` —
слежение за шаттлом, `C` — следующая камера, `1 / 2 / 3` — режим камеры лидара.

## Демо-режим (`#/demo`)

Раскладка под экран 1920×1080 для показа на проекторе — без телеметрии и
настроек, только то, что нужно зрителю:

- **экран 1** — схема территории, **экран 2** — облако точек лидара (крупно, во всю ширину);
- **четыре бортовые камеры** одновременно: фронтальная, левая, правая, кормовая;
- **статус движения** крупной плашкой: «В движении · 11,4 км/ч», «Остановлен»,
  «Посадка / высадка · двери открыты», «Стоп · пешеход» (мигает красным), «Пауза»;
- **следующая остановка** и расстояние до неё либо отсчёт до отправления;
- **лента событий**: пешеход в коридоре и возобновление движения, подъезд и
  прибытие на остановку, открытие и закрытие дверей, отправление.

Предупреждение о пешеходе появляется только когда помеха реально влияет на
скорость (ближе 9,5 м), с задержкой на снятие — сообщения не мигают.

Кнопки в правом верхнем углу: регулятор скорости `− ×N +` (до ×10), пауза,
полноэкранный режим (`⛶`) и выход. `Пробел` — пауза, `+` / `−` — скорость,
`Esc` — выход из режима. Ссылку `#/demo` можно открыть сразу
на презентационном экране.

## Страница «Редактор карты» (`#/editor`)

Карта — это отдельный файл `*.map.json`. Редактор позволяет собрать свою:

| Инструмент | Что делает |
|---|---|
| Выбор | выделить объект, перетащить, потянуть за маркеры — изменить размер |
| Здание | протянуть прямоугольник; имя, подпись, тип, высота, поворот, габариты |
| Деревья | клик — одно дерево, движение с зажатой кнопкой — аллея; размер кроны настраивается |
| Дороги | три типа: двухполосная (с осевой разметкой), однополосная, пешеходная; клики задают точки, двойной клик или `Enter` завершает |
| Ландшафт | прямоугольные участки: газон, вода, покрытие, поле |
| Маршрут | клики добавляют точки; клик рядом с участком вставляет точку в него; скругление углов и замкнутость |
| Остановка | клик ставит остановку, она примагничивается к маршруту; код, название, время стоянки |
| Пешеходы | маршруты прогулок и число пешеходов на них |
| Удалить | клик по объекту удаляет его |

**Изменение размеров мышью.** У выделенного объекта появляются маркеры
постоянного экранного размера: восемь белых — по углам и серединам сторон
(тянут габариты, противоположная сторона остаётся на месте), оранжевый сверху —
поворот здания (с `Shift` — шаг 15°). У дерева маркер задаёт радиус кроны,
у дороги и пешеходного маршрута маркеры стоят в каждой вершине ломаной.

Правая кнопка мыши — панорама, колесо — масштаб, `F` — вписать карту в экран,
`Ctrl+Z` / `Ctrl+Shift+Z` — отмена и возврат, `Delete` — удалить выделенное.

Кнопки сверху: **Открыть файл**, **Сохранить в файл** (скачивает `*.map.json`),
**Применить** (карта сохраняется в браузере и сразу подхватывается симуляцией),
**В симуляцию →**.

## Устройство проекта

```
src/
  map/
    schema.ts        формат файла карты, пресеты дорог и проверка при загрузке
    rudn.map.json    карта РУДН по умолчанию (20 корпусов, 297 деревьев, 3 остановки)
    runtime.ts       сборка рантайма: маршрут, остановки, препятствия для лидара
    storage.ts       localStorage + выгрузка/загрузка файла карты
  sim/
    geometry.ts      векторная математика, скругление ломаных, параметризация маршрута
    engine.ts        динамика шаттла, расписание остановок, пешеходы, реакция на помеху
    lidar.ts         модель вращающегося 16-канального лидара и трекер объектов
    store.ts         состояние интерфейса и телеметрия (zustand)
    events.ts        журнал событий для демо-режима (пешеходы, остановки, двери)
  components/        сцены симуляции: карта, лидар, камеры, телеметрия, демо-режим
  editor/
    EditorPage.tsx   инструменты, история, сохранение и панель свойств
    EditorScene.tsx  сцена редактора
    handles.ts       маркеры изменения размера и их применение
```

### Как считается лидар

Модель повторяет VLP-16: 900 азимутов × 16 каналов (от −16° до +6°), 8 оборотов в
секунду, дальность 55 м — около 115 тысяч точек в секунду. Каждый кадр
досчитывается только тот сектор, который «проехал» луч. Для азимута решается
плоская задача пересечения с препятствиями (повёрнутые прямоугольники зданий,
цилиндры стволов и крон, цилиндры пешеходов), затем для каждого канала
проверяется высота попадания: стена, крона, ствол, асфальт или отсутствие
отражения. Точки живут в буфере около 0,7 с и плавно гаснут, поэтому виден след
разворачивающегося луча. Раз в оборот накопленные попадания сводятся в список
обнаруженных объектов с дальностью и числом точек.

### Как ведёт себя шаттл

Крейсерская скорость 12 км/ч, продольный профиль ограничивается кривизной
маршрута, торможением к остановке и помехой в коридоре движения. Пешеход,
попавший в коридор шириной ±2,4 м на дистанции до 15 м, вызывает экстренное
торможение; после того как он уходит, движение возобновляется. На остановке
открываются двери, меняется число пассажиров, затем шаттл едет дальше.
